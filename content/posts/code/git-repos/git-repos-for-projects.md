### New Git repo info

This will contain some information about my Git repos.

--------

I have started to post my code on places other then GitHub.

Internally I use Gitea since i've just had it running for so long and it works well.
But on the Git subdomain for this website I use Forgejo.

Forgejo is a fork of Gitea and works just about the same, although my Git server may sometimes go down when I do server updates or maintenance so I will try to keep my code mirrored to either GitHub or Codeberg.

I do have a Codeberg account now too, if I don't have some of my code on GitHub it'll either be on the Forgejo or Codeberg.
